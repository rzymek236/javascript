Teoria JavaScript - Michał Rzymowski, 3F, nr 22

1. Kiedy powstał JavaScript?

JavaScript powstał w 1995 roku.

2. Dlaczego jest to język skryptowy?

Jest językiem skryptowym, ponieważ jest interpretowany i może być wykonywany bez wcześniejszej kompilacji do kodu maszynowego, np. w przeglądarce.

3. Gdzie jest wykonywany JavaScript: po stronie klienta czy serwera?

JavaScript może być wykonywany po stronie klienta, np. w przeglądarce, oraz po stronie serwera, np. przy użyciu Node.js.

4. Dlaczego JavaScript jest bezpiecznym narzędziem?

W przeglądarce JavaScript ma ograniczone uprawnienia dostępu do zasobów komputera użytkownika, co zwiększa bezpieczeństwo.

5. Czy JavaScript jest językiem obiektowym? Jeśli tak, to dlaczego?

Tak. JavaScript jest językiem obiektowym, ponieważ wykorzystuje obiekty, metody i zdarzenia. Strukturę dokumentu opisuje DOM.

6. Wymień trzy zalety JavaScript.

1) Prostota nauki. 2) Uniwersalność i duża liczba przykładów. 3) Możliwość tworzenia interaktywnych stron bez ciągłego przeładowywania.

7. Framework to:

Framework to rodzaj programu lub zestawu narzędzi ułatwiających tworzenie innych programów.

8. Do aplikacji mobilnych można użyć frameworka:

React Native.

9. Aplikacje responsywne to:

Aplikacje, których wygląd i układ dopasowuje się do rozmiaru ekranu urządzenia.

10. Wyjaśnienie kodu:

<input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')">

Tworzy przycisk. Po kliknięciu uruchamia funkcję WinOpen().

11. Wyjaśnienie kodu:

window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Otwiera stronę obraz.html w nowym oknie o nazwie okienko. Ustawia m.in. wysokość, szerokość oraz położenie okna, a także ukrywa wybrane paski.

12. Opisz instrukcję window.close().

Instrukcja window.close() zamyka bieżące okno, jeśli przeglądarka pozwala na jego zamknięcie.
